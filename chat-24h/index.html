전환 개요와 동작 규칙

구분내용
대상인앱·웹 채팅 상담 중 상품 및 주문관련 문의(커머스)만 24시간 운영으로 전환합니다.
제외시공/이사/청소/제품설치 서비스 문의와 콘텐츠 수익화 프로그램은 상담원 직결 구조이므로 평일 09~18시를 유지하고, 야간에는 운영시간을 안내합니다.
야간 정의평일 18:00~익일 08:59, 토·일·공휴일 종일 (상담원 실시간 응대가 없는 시간 전체)
야간 상담원 연결연결(Handover) 대신 1:1 문의 접수를 유도합니다. 고객이 접수를 선택하면 1:1 문의 작성 화면이 모달로 열리고, 대화 요약본이 본문에 자동 입력됩니다.
비회원회원 정보가 없어 주문·배송 API 조회가 불가하므로 KMS·FAQ 응대만 하고, Depth2(주문 조회·배송 현황·상품 문의·반품/교환) 선택이나 인증이 필요한 요청은 즉시 상담원 연결 대상입니다. 주간은 바로 연결하고, 야간에는 로그인을 유도합니다. 로그인하면 인증 후 API 조회가 가능해지므로 회원과 동일하게 챗봇이 응대를 이어가고, 그래도 상담원 확인이 필요하면 1:1 문의 접수로 넘어갑니다. 거부하면 도움이 될 안내와 상담원 상담 가능 시간을 안내하고 챗봇 선에서 마무리합니다.
시간 판정 기준상담원 연결을 요청한 시각으로 판정합니다. 채팅에 처음 진입한 시각은 기준이 아닙니다. (5장 경계 시간 참조)

챗봇 ↔ 1:1 문의 연동 요건

1:1 문의 작성 화면은 채팅 위에 모달로 열리고, 닫힐 때 접수 결과를 챗봇이 받아서 다음 멘트를 분기합니다.

항목내용
① 모달 열기챗봇의 [문의 접수하기] 버튼 → 1:1 문의 작성 화면을 모달로 호출. 이때 문의 유형(매핑값)·주문번호·제목·대화 요약본을 초기값으로 전달
② 본문 초기값대화 요약본을 본문에 넣어 두고, 고객이 수정·추가할 수 있게 둠. 발화 전문은 접수 시 상담 내역과 함께 상담원 콘솔에 전달 (원문이 정본, 요약은 참고용)
③ 접수 완료 콜백접수 성공 → 모달 닫힘 → 챗봇에 submitted 전달 → 접수 완료 안내 멘트 → 추가 문의 여부 확인 → 종료
④ 미접수 콜백취소·닫기 → 챗봇에 cancelled 전달 → "추가로 문의하실 내용이 있으신가요?" → 대화 계속 / 접수 재안내 / 종료
⑤ 채널 태그이렇게 생성된 1:1 문의는 콘솔에서 야간 챗봇 이관건으로 식별할 수 있는 구분값을 가짐
⑥ 첨부·인증채팅에서 올린 이미지가 1:1 문의로 함께 넘어가야 하며, 로그인 세션의 본인확인 결과를 승계함 (AICX 회신 필요 항목)
