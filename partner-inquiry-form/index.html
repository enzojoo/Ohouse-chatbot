파트너센터 1:1 문의 유형별 입력 템플릿

문의 유형을 고르면 요청 구분 드롭다운이 붙고, 요청 구분에 따라 받는 항목이 바뀌는 구조입니다. 아래 화면에서 직접 골라 보면서 확인할 수 있습니다.

콘솔 기능(드롭다운 선택지 직접 설정, 선택값에 따른 항목 표시·숨김)이 모두 된다고 가정한 초안입니다. 확인이 필요한 사항은 맨 아래에 정리했습니다. 비중은 Zendesk Q3(7~9월) 게시판 6,372건 전수 분류 기준입니다.

1. 입력 흐름

STEP 1 · 문의 유형

9개 중 1개 선택 (드롭다운)

STEP 2 · 요청 구분

유형마다 다른 선택지가 나옴. 목록 끝은 「잘 모르겠어요」

STEP 3 · 유형별 항목

요청 구분에 맞는 항목만 표시. 앞 항목 선택값에 따라 추가 항목이 더 나오기도 함

STEP 4 · 공통 항목

제목, 문의 내용, 첨부, 회신 이메일, 연락처 (현재 화면 그대로)

2. 문의 유형 전체 (카드나 요청 구분을 누르면 아래 화면에 바로 적용됨)

4. AICX 확인 필요 사항

  1. 드롭다운 선택지 직접 설정: 「요청 구분」과 각 단일 선택 항목의 선택지를 우리가 정할 수 있는지
  2. 조건부 표시: 요청 구분이나 앞 항목 선택값에 따라 항목을 보이거나 숨길 수 있는지. 안 되면 유형별 공통 항목(주문번호·사유·첨부)만 두고 나머지는 문의 내용 안내문으로 돌려야 함
  3. 입력값 전달: 요청 구분과 항목 입력값이 상담사 화면과 LLM 상담유형 분류에 같이 넘어가는지. 넘어가야 ECA 소분류가 정확하게 찍힘
  4. 문서 첨부: 입력 형식에 이미지·영상 첨부만 있고 엑셀 등 문서 첨부가 없음. 대량 취소·배송상태 일괄 변경 때 주문번호 목록을 엑셀로 받던 건은 지금은 「여러 줄 입력」에 붙여넣는 방식으로 잡음
  5. 체크박스 다중 선택: 「이미 해 본 조치」처럼 여러 개를 고르는 항목이 되는지
  6. 유형 이름 변경: 「광고 관리」를 「광고/프로모션 관리」로 바꾸면 ECA 상담유형 이름도 맞춰야 하는지 (AICX→ECA 매칭은 이름 완전 일치 기준)
  7. 입점 전 문의: 1:1 문의는 로그인한 파트너만 쓸 수 있어서 유형에 넣지 않음. 입점 신청 후 서류를 고치려는 예비 파트너가 로그인할 수 있는지만 확인 필요
