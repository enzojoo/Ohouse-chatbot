읽는 법

- 월평균은 2026년 7~9월 Zendesk 채팅·게시판 25,110건 전수 분류를 3으로 나눈 값입니다. 노션 [위클리 공유] 페이지 수치와 같은 기준입니다.
- 처리 흐름(접수·처리·이관·답변)은 노션 「파트너센터 문의 유형별 처리 흐름 (As-Is)」 기준입니다. "추정" 표시는 문서로 확인되지 않은 내용입니다.
- 단순 안내형에는 방법·정책 문의와 함께 주문·검수·노출·담당 MD 같은 상태 확인 문의가 들어 있습니다. 권리보호(월 18건)는 권리보호센터 신고 양식으로 따로 들어오는 건이라 As-Is 수치를 쓰고 전체 합계에서 뺐습니다.

- 막대와 "챗봇이 하려면"의 비율은 7~9월 전수 분류 25,110건 가운데 유형별로 뽑은 상담을 KMS 원문과 대조한 판정입니다. 유형마다 ±10%p 안팎의 오차가 있습니다.

- 챗봇 처리 = 월평균 × (켠 권한으로 해결되는 비율의 합)입니다. 예를 들어 Write 권한을 끄면 취소·반품 같은 처리 건은 챗봇이 정보를 받아 상담원에게 넘기는 데까지만 하므로, 처리 건수에 넣지 않습니다.

- 클레임 상태 변경의 "교환→반품 전환"은 KMS 기준(오로라 기능 미지원, 어드민 교환관리에서 교환불가 처리 후 반품 접수)으로 고쳐 적었습니다.
